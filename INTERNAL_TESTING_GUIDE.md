# 🧪 Internal Testing Setup Guide

## 📋 What We'll Do
1. Create Google Play Developer Account
2. Set up Internal Testing

## 🚀 Step-by-Step Process

### Step 1: Create Google Play Developer Account
```
🌐 Go to: https://play.google.com/console/signup
💳 Pay: $25 (one-time fee)
📧 Use: Your business email
⏱️ Time: 5-10 minutes
```

### Step 2: Create New App
```
1. Click "Create app"
2. Select "No, this app doesn't use Android App Bundles"
3. Fill basic info:
   - App name: "Biochar Management System"
   - Default language: English
   - App or game: App
   - Free or paid: Free
```

### Step 3: Set Up Internal Testing
```
📱 In Play Console:
1. Go to "Testing" → "Internal testing"
2. Click "Create new release"
3. Upload your APK file
4. Fill release notes
5. Save and publish
```

### Step 4: Add Testers
```
👥 Add Testers:
1. Go to "Internal testing" page
2. Click "Add testers" 
3. Enter email addresses (up to 100)
4. Click "Add"

📧 Testers will receive:
- Opt-in link
- Download instructions
- Feedback form
```

### Step 5: Share APK Directly (Alternative)
```
📧 Direct Sharing:
1. Email the APK file
2. Use Google Drive/Dropbox
3. Share via WhatsApp/Telegram

📱 Installation:
1. Enable "Unknown sources" on Android
2. Download APK
3. Install and test
```

## 📱 How Testers Install

### Method 1: Play Console Link
```
1. Tester receives email from Google Play
2. Click "Become a tester" link
3. Accept invitation
4. Download from Play Store
5. Install and test
```

### Method 2: Direct APK
```
1. Enable "Install unknown apps"
   Settings → Apps → Special access → Install unknown apps
2. Download APK file
3. Tap to install
4. Grant permissions
5. Start testing
```

# Biochar Management System - Quick Start Guide

## 🚀 5-Minute Setup Guide

### 1️⃣ Install the App (2 minutes)
1. Download `Biochar-Management-System.apk`
2. Enable "Install from unknown sources" in Android Settings
3. Install the APK file
4. Grant Location permission when asked

### 2️⃣ Create Account (1 minute)
1. Open the app
2. Click **"Sign Up"**
3. Fill: Name, Email, Password, Select Role
4. Click **"Sign Up"** → You'll go to Login page

### 3️⃣ Log In (30 seconds)
1. Enter Email and Password
2. Select your Role (same as signup)
3. Click **"Sign In"**

### 4️⃣ First Procurement Record (2 minutes)

#### Add Vehicle (Optional - if using vendor vehicle):
1. Go to **"Add Vendor"** from sidebar
2. Fill: Vehicle Number, Weight, Type, Name, State, District, Village
3. Click **"Add Vehicle"**

#### Record Procurement:
1. Go to **"Raw Biomass Procurement"**
2. Fill Trip Details:
   - Select Source of Biomass
   - Enter Name
   - Select Vehicle Type (Own/Vendor)
   - Enter Vehicle Number & Weight
   - Select State, District, Village
3. **Take Vehicle Photo**:
   - Click "Upload Vehicle Image"
   - Take photo → GPS captures automatically ✅
   - Latitude/Longitude auto-fill ✅
4. Fill Weight Details:
   - Enter Gross Weight
   - **Take Weight Photo** → NET WT extracts automatically ✅
5. Click **"Save Procurement Data"** ✅

### 5️⃣ View Your Records
- Scroll down to see "Procurement Records" table
- Click photos to view with GPS metadata
- Use Export Excel to download records

## ❓ Common Issues & Quick Fixes

| Issue | Quick Fix |
|-------|-----------|
| GPS not capturing | Enable Location permission in Settings |
| Can't log in | Check role matches signup role |
| Photos not showing | Check Storage permission |
| NET WT not extracting | Take clear photo of receipt, or enter manually |
| Form not saving | Check internet connection, wait for success message |

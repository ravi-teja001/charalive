## 🚀 Quick Transfer Methods

### Method 1: WhatsApp (Easiest)
1. Open WhatsApp on your computer or use WhatsApp Web
2. Send `Biochar-Management-System.apk` to yourself
3. Open WhatsApp on your phone
4. Download the file
5. Install directly from WhatsApp

### Method 2: Email
1. Attach `Biochar-Management-System.apk` to an email
2. Send to your own email address
3. Open email on your phone
4. Download the attachment
5. Install the APK

### Method 3: USB Cable
1. Connect your Android phone to computer via USB
2. Enable "File Transfer" mode on phone
3. Copy `Biochar-Management-System.apk` to phone's **Downloads** folder
4. Disconnect USB
5. Open Downloads on phone
6. Tap the APK file to install

### Method 4: Google Drive
1. Upload `Biochar-Management-System.apk` to Google Drive
2. Open Google Drive app on your phone
3. Download the APK file
4. Install from Downloads folder

---

## 📲 Installation Steps (On Your Phone)

1. **Enable Installation from Unknown Sources:**
   - Go to **Settings** → **Security** (or **Apps** → **Special access**)
   - Enable **"Install unknown apps"** or **"Allow from this source"**
   - Select the app you'll use (Chrome, Files, WhatsApp, etc.)

2. **Download the APK:**
   - Use any of the methods above to get the APK on your phone

3. **Install:**
   - Open **Files** or **Downloads** app
   - Find `Biochar-Management-System.apk`
   - Tap on it
   - Tap **"Install"**
   - Wait for installation to complete
   - Tap **"Open"**

4. **First Launch:**
   - Sign up with email and password
   - Select your role:
     - Stock Point Supervisor
     - Incharge
     - Plant Supervisor
   - Start using the app!

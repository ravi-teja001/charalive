  SHARE WITH TEAM - AVOID .BIN FILE ISSUE
============================================

DON'T share the .apk file directly (WhatsApp/Telegram may save it as .bin).

DO share this file instead:

  >>>  Biochar-Management-System-INSTALL.zip  <<<

Recipient:
  1. Download the ZIP
  2. Open it (Files app or any unzip app)
  3. Extract → get "Biochar-Management-System-LATEST.apk"
  4. Tap the .apk → Install

If they already got a .bin file:
  - Open Files → find the .bin file
  - Long-press → Rename
  - Change .bin to .apk (e.g. document.bin → app.apk)
  - Tap the file → Install

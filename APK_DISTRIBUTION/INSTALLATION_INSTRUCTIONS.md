## 📥 How to Install on Android Device

### Method 1: Direct Transfer (Recommended)

1. **Transfer the APK to your Android device:**
   - **Email:** Send the APK as an attachment to yourself, then open it on your Android device
   - **USB Cable:** Connect phone to computer, copy APK to phone's storage
   - **WhatsApp/Telegram:** Send the APK file via WhatsApp or Telegram to yourself
   - **Google Drive/Dropbox:** Upload APK to cloud storage, then download on phone
   - **Bluetooth:** Transfer via Bluetooth from computer to phone

2. **Enable Installation from Unknown Sources:**
   - Open **Settings** on your Android device
   - Go to **Security** or **Apps** or **Install unknown apps**
   - Enable **"Install unknown apps"** or **"Allow from this source"**
   - If prompted, select the app you'll use to install (Chrome, Files, etc.)

3. **Install the APK:**
   - Open **Files** app (or any file manager) on your Android device
   - Navigate to the location where you saved the APK file
   - Tap on `Biochar-Management-System.apk`
   - Tap **"Install"**
   - Wait for installation to complete
   - Tap **"Open"** to launch the app

### Method 2: QR Code (If Available)

1. Generate a QR code for the APK file
2. Scan QR code with your phone's camera
3. Download and install the APK

## 🔒 Security Settings for Installation

**Android 8.0 and above:**
- Go to **Settings** → **Apps** → **Special access** → **Install unknown apps**
- Select your browser/file manager
- Toggle **"Allow from this source"** to ON

**Android 7.0 and below:**
- Go to **Settings** → **Security**
- Enable **"Unknown sources"**

## 🆘 Troubleshooting

### "Install blocked" or "Installation failed"
- Make sure "Install unknown apps" is enabled for your file manager/browser
- Check if you have enough storage space
- Try downloading the APK again

### "App not installed"
- Uninstall any previous version of the app first
- Make sure you're using the correct APK file
- Check Android version compatibility (requires Android 5.0+)

### "Can't open file"
- Make sure you have a file manager app installed
- Try opening from Downloads folder
- Use Chrome to download and install directly
